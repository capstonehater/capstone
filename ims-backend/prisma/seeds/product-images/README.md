# Café Salvacion seed product images

These 67 WebP POS thumbnails are synthetic product photographs generated with the five menu posters supplied for this project as visual references. They are designed to represent the seeded catalog and its ingredients; they are not photographs of the café's actual finished products. Product names, stable URLs, and poster references are listed in `../product-image-manifest.json`.

`ensureSeedProductImages` copies these files to `ims-backend/product-images/` when the catalog is seeded. The runtime directory is ignored by Git because the application also uses it for uploaded images.
